# НС АЦП — Мульти-топологическая среда самомаршрутизации

Имитационная модель децентрализованной самомаршрутизирующейся системы основных измерительных нейронов (ОИН) для конвейерных аналого-цифровых преобразователей на базе PySide6.

## Поддерживаемые топологии
- **Тороидальная матрица 6x6**: классическая регулярная прямоугольная решетка с горизонтальным и вертикальным замыканием.
- **Ромбовидная архитектура**: конвейерная структура с переменной шириной слоев ($W = [4, 6, 8, 6, 4]$) для создания буферных зон маневра.
- **Восьмиконечная звезда (Star-8, 4 и 6 входов)**: радиально-кольцевая структура с мостами между ветвями.
- **Гексагональная сота (Honeycomb, deg=3)**: планарная сотовая конвейерная решетка с продвижением вперед при обходе сбоев.
- **Симметричная звезда C8 (Sym-Star8, deg=3)**: изоморфная 8-лучевая звезда с замкнутым хордовым кольцом $C_8$.

## Основные возможности
- **Децентрализованная самомаршрутизация**: узлы принимают решения строго локально на основе зондирования смежных каналов, без центрального арбитра и без опроса соседей.
- **Потактовое построение конвейера**: каскадное бронирование ОИН ($q$ этапов) и динамическое время жизни заявки ($T = 3q + 2$).
- **Моделирование аппаратных сбоев**: интерактивное отключение/включение любого нейрона в реальном времени кликом по узлу.
- **Машина времени**: пошаговый просмотр истории вперед/назад, перемещение по тактам через слайдер, перемотка до завершения, ветвление при изменении состояния.
- **Адаптивная визуализация**: векторная отрисовка связей, маршрутов заявок и состояний узлов без коллизий элементов.

## Установка и запуск

```bash
pip install PySide6
python main.py
```
