# НС АЦП (Имитационная модель самомаршрутизации 6x4)

Имитационная модель децентрализованной самомаршрутизирующейся сети основных измерительных нейронов (ОИН) на базе PySide6.

## Особенности
- Тороидальная матрица 6 строк × 4 столбца (закольцована по горизонтали и вертикали).
- 4 стартовые измерительные заявки, поступающие на входной слой через такт.
- 10 тактов на вычисление каждым нейроном.
- Однократность вычислений (после завершения расчета узел переходит в статус `Завершен` и сохраняет след).
- Алгоритм поиска свободных ресурсов в порядке приоритета: свой нижний -> левый -> правый.
- Машина времени: пошаговый просмотр вперед/назад, ползунок тактов и кнопка мгновенного перехода в конец вычислений.
- Интерактивные кнопки нейронов с возможностью выключения (симуляция аппаратного сбоя).

## Запуск
```powershell
pip install PySide6
python main.py
```
